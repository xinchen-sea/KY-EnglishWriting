# 考研英语大作文 · 逐句拼装模板（AI归来 27版）

单文件、零依赖、可离线的交互式大作文工具：拿到任意一道真题，点选短语 + 填几个题干词，就能逐段拼出完整作答。

打开方式：直接用浏览器打开 `index.html`，或访问 GitHub Pages 地址。

## 覆盖范围

| 项目 | 数量 |
|---|---|
| 题型分支 | 8（图表·动态单方向 / 动态多方向 / 静态图 / 双图表 / 万能场景 / 图画 / 图画+图表 / 文字） |
| 真题预设 | 20（23英二健康素养、19英二毕业生、24英二劳动实践、26英一养老机器人、26英二户外活动、25英一家电、22英二快递、25英二老人休闲、2012例外表格、24英一公园、23英一龙舟、22英一听讲座、20英一拖延、2010文化火锅、2011环保、2001油灯、文字样题1/2、2009网络、2013英二兼职） |
| 可切换句型 | 349 处（每处带中文注释与适用语境） |
| 可点击词库 | 770 条（六大方面、措施角度、连接词、从句、短语、动词/程度、约数/峰值/排序/对比衔接等） |
| 槽位 | 106 个，未填显示【标签】，已填高亮 |

## 功能

- 顶部：题型按钮、真题预设、中英对照 / 考场精简 / 英文自动细节 / 注释 / 套用标注、撤销、清空、复制
- 每句一个"方案"下拉（7 个原因方案、3 个静态图公式、6 个万能句…），切换即时重算
- 句子内每个可替换成分都是槽位，点击弹出词库，可搜索、点选或手输
- 预览按第一/二/三段分块，句级中英对照、分段词数、一键复制全文
- 状态存 localStorage，切预设与清空前自动快照，撤销 30 步（Ctrl+Z）
- 自动英文细节：主谓一致、句首大写、逗号后非专名降小写

## 技术

单文件：1 个 `<style>`、1 个 `<script>`，IIFE + `"use strict"`，无 CDN、无外链字体、无外链图片，离线可用。

回归测试：jsdom 全量遍历 题型 × 预设 × 全部下拉 × 全部槽位（方案切换 605 次、子下拉 1602 次、槽位点击 226 次、词库点选 2444 次），运行时错误 0。

## 使用建议

先用下拉选一条真题预设看整篇效果 → 换自己的题目时只改「题型按钮 + 主题词/数值/图例」三类槽位 → 打开"套用标注"核对每句用的哪条待选句 → 打开"考场精简"默写。

> 本工具是写作脚手架，句子组织与用词请按题目微调；背诵与套用需自行练习，不能替代审题。
