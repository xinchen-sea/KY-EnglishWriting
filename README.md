# 考研英语 · 大作文 / 小作文 模板（四版 · 双主题）

AI归来 27 版讲义配套的**逐句拼装模板**，一个页面里放了 4 个独立版本，每个版本都支持**深色 / 浅色**两套主题。

> 在线地址：<https://kyew.xinchen-sea.top/> 或 <https://xinchen-sea.github.io/KY-EnglishWriting/>
> 单文件、零依赖、可离线：把 `index.html` 下载下来双击即可用。

## 四个版本

| 标签 | 内容 | 原生主题 |
|---|---|---|
| 大作文 · 版式一 | 图表 / 双图表 / 图画 / 图画+图表 / 文字，8 题型 · 20 套真题预设 | 浅色 |
| 大作文 · 版式二 | 同一套大作文内容，拼装台式布局 | 深色 |
| 小作文 · 版式一 | 书信 / 通知·告示 / 纪要，4 题型 · 16 套真题预设 · 50 个功能句 | 浅色 |
| 小作文 · 版式二 | 同一套小作文内容，拼装台式布局 | 深色 |

## 怎么用

1. 顶部标签切换四个版本；
2. 右上角 `☾ 深色 / ☀ 浅色` 切换主题（快捷键 **T**），选择与所在页面会被记住；
3. 页面内：先选题型 → 载入真题预设 → 点金色【】槽位填词 → 复制全文；
4. 直链：`#bigA` `#bigB` `#smallA` `#smallB` 可直接定位到某个版本。

## 说明

- 每个版本都是独立页面（iframe 隔离），互不影响；
- 版式二原生为深色，浅色由色板映射生成；版式一原生为浅色，深色由变量与组件层覆盖；
- 主题切换优先注入样式（不重载、不丢选择），浏览器限制跨文档访问时自动降级为重渲染。

## 技术

单文件 HTML，外层 1 个 `<style>` + 1 个 `<script>`，四个页面以内嵌字符串形式随文件分发；无 CDN、无外链字体与图片，离线可用。
